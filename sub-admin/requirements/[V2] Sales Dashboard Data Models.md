# **Sales Dashboard Data Models**

This document outlines the data structures used within the index\_dashboard.kte file to generate, process, and visualize the sales performance data. All data is mocked and stored in memory.

## **1\. Base Transaction Model (Raw Data)**

This is the fundamental data structure representing a single transaction. A large array of these objects is generated when the page loads.

* **Location:** Generated in generateData()  
* **Structure:** Array\<Transaction\>

Each Transaction object has the following structure:

\`\`\`json

{  
  "date": "YYYY-MM-DD",  
  "revenue": 120.50,  
  "cogs": 75.20  
}  
\`\`\`

|

| Field | Type | Description |  
| date | String | An ISO 8601 date string (YYYY-MM-DD) representing the day the transaction occurred. |  
| revenue | Number | The total revenue generated by this single transaction. |  
| cogs | Number | The "Cost of Goods Sold" associated with this transaction, used to calculate profit. |

## **2\. Period Metrics Model (KPI Aggregation)**

This structure represents the aggregated metrics for a specific time period (e.g., "Last 90 Days"). It is used to populate the main KPI cards at the top of the dashboard.

* **Location:** Returned by calculateMetrics(data)  
* **Structure:** Object

\`\`\`json

{  
  "totalRevenue": 55020.10,  
  "totalCogs": 33005.50,  
  "transactionCount": 480  
}  
\`\`\`

| Field | Type | Description |  
| totalRevenue | Number | The sum of all revenue fields from the base transactions in this period. |  
| totalCogs | Number | The sum of all cogs fields from the base transactions in this period. |  
| transactionCount | Number | The total number of transactions in this period (i.e., the length of the data array). |

## **3\. Grouped Chart Data Model**

This structure is an array of objects used to plot data on the two charts (Revenue & Profit Margin, and Transactions). It aggregates all transactions by a specific period (day, week, or month) depending on the selected date range.

* **Location:** Returned by groupDataByPeriod(data, period)  
* **Structure:** Array\<GroupedData\>

Each GroupedData object in the array looks like this:

\`\`\`json

{  
  "date": "2025-11-01",  
  "revenue": 8500.00,  
  "cogs": 4100.20,  
  "transactions": 95  
}

\`\`\`

| Field | Type | Description |  
| date | String | An ISO 8601 date string (YYYY-MM-DD) representing the start of the grouped period (e.g., the day, the first day of the week, or the first day of the month). |  
| revenue | Number | The total revenue for all transactions within this grouped period. |  
| cogs | Number | The total COGS for all transactions within this grouped period. |  
| transactions | Number | The total count of transactions within this grouped period. |  
This array is then used to create separate arrays for chart labels (labels), revenue (revenueData), profit margin (profitMarginData), and transaction counts (transactionData).
